# 奶娃璀璨宝石 · GitHub Pages 人机试玩

[打开游戏](https://jinming-yang.github.io/naiwa-splendor/)

- 2–4 人席位，你与 1–3 位 AI 对战；轻松、标准、挑战三档难度。
- 90 张发展卡与 10 位贵族分别使用不同奶娃图片。
- 内置完整规则、目录和常见问题。
- 进度保存在当前浏览器；无需账号、无外部 AI 服务费用。

这是 GitHub Pages 静态人机版。开房与多人联机需另外部署服务器。

`index.html` 已包含全部程序、样式和图片，可直接通过 GitHub Pages 发布，不依赖外部图片地址。

`source.zip` 内含可编辑的 React/Vite 源码和素材。解压后安装 Node.js 22.13+，运行 `npm install`、`npm run build`，再把生成的 `docs/index.html` 上传到此仓库根目录即可更新。

非官方主题同人作品。规则参考璀璨宝石基础版说明书；图片来源清单位于源码包 `public/art/sources.json`。
